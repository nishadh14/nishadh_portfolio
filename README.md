# Nishadh Nikam — Portfolio

**Live:** https://nishadh-portfolio.onrender.com/

Professional animated portfolio built with React, Vite, TypeScript, Tailwind CSS, and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Customize

Edit content in `src/data/portfolio.ts` (skills, projects, experience, contact links).
